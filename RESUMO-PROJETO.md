## 🚀 Como Usar

### Instalação Rápida (5 minutos)
```bash
# 1. Configure o WordPress
cp wp-config-sample.php wp-config.php
# Edite wp-config.php com suas credenciais

# 2. Instale o WordPress
# Acesse: http://seu-site.com/wp-admin/install.php

# 3. Ative o tema
# WordPress Admin > Aparência > Temas > Ativar "Marketeria"

# 4. Ative o plugin
# WordPress Admin > Plugins > Ativar "Marketeria Core"

# 5. Configure
# Aparência > Personalizar (configure cores e logo)
# Marketeria (menu) > Configure informações da empresa
```
